## Browser click pagination

`CLICK <xpath>` advances a live Playwright page and repeats the `SELECT`
extraction after each click. `PAGES <integer>` limits the number of page
snapshots, including the initial page. If omitted, the cap is 100 pages.

```sql
SELECT //li/text() AS name
FROM https://example.com/results
    CLICK //button[@aria-label='Next']
    PAGES 10
    CRAWLER playwright
```

`CLICK` requires a non-empty XPath and a Playwright crawler. `PAGES` requires
`CLICK` and must be positive. `FOLLOW` and `CLICK` cannot be combined in one
`FROM` clause. The crawler stops early when the control is absent or disabled,
or when a click leaves the page unchanged. The executor streams rows from
each page in order.
`CLICK` inside a URL-producing `FROM (SELECT ...)` subquery is unsupported.

WSQL transpiles this form to wxpath's `//wx:paginate(...)` segment. Install
WSQL's `playwright` extra and Chromium before running it.
